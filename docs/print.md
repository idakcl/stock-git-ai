# 打印说明

全站打印共用一份纸张设置，CSV 导出与打印互不影响。本文只说明「出什么纸、每页多少行、哪些选项会影响结果」，实现细节见 [README 打印排版](../README.md#打印排版纸张字号与分页)。

## 1. 入口与纸张

| 位置 | 按钮 | 说明 |
| --- | --- | --- |
| 销售 / 采购 / 订单列表 | 打印 | 按当前筛选与排序打印整表 |
| 列表行 | 打印 / CSV | 单张单据 A4 版式、单张明细 CSV |
| 订单批量 | 打印勾选订单列表 / 详情页 | 详情页可选「直接打印」或「隐藏金额打印」，每单单独一页 |
| 单据详情页 | 打印 / CSV | 与列表行同一套版式 |
| 订单模板 | 打印 / 空表 | 空表按当前纸张出纸，用于手填 |

纸张在「打印设置」（`PrintHeaderToggle`）里选，全站共用并记在 `localStorage`：

- **A4**（默认，纵向）或 **A5**；也可以填自定义宽高（mm）。
- 方向：纵向 / 横向。每页行数不随方向变化，按纸高统一推算。
- 面板会显示当前预算：`每页 N 行 = 标头 X 行 + 商品 Y 行（首页）`、`后续页：商品 N 行`。手动改过行数会标「手动」，并同时显示自动值。

## 2. 每页行数是怎么算的

1. 纸张高度减去**虚拟边距**（至少 24mm，窄纸按纸高 16% 封顶）得到可排版高度；
2. 按 13px / 12px 正文字号与 `line-height: 1.25` 折算行数；
3. 首页扣掉单头预留行数，末页扣 2 行给落款；
4. 明细按**折行后的行数**累计切页（名称太长折成两行就占两行），不是按条目数。

因此「第二页只有两三行」「每页比预期少几行」都是正常的留余量，不是 bug。真机边距比设置大时（iOS / AirPrint 常见 12.7mm），可在打印设置里手动把每页行数调小。

## 3. 会改变出纸内容的选项

- **跨页表头**（默认开）：开＝每页都重复商品表头；关＝整份明细一张连续大表，表头只印第一页。选择同样记在 `localStorage`。
- **隐藏金额打印**（仅订单批量详情）：去掉单价、折扣、行金额、订单金额、订金、未收 / 未付等全部金额；单头不显示状态，第二行只留「共 N 项商品」。
- **显示用户信息**（单据详情）：勾选后落款印在商品列表下方；字段全空时不产生落款块。
- 无行折扣时自动隐藏「折扣率 / 本次折扣」两列；有整单折扣时保留「折后金额」列。

## 4. 打印对话框里的设置

页面负责生成分页后的静态表格，浏览器负责出纸。要得到与版面一致的结果：

- **缩放**保持 100%（不要「适合页面」）；
- **页边距**选「默认」或「最小」；选了较大的边距，每页会少排几行；
- 需要表格底色 / 状态点颜色时勾选**背景图形**（各浏览器文案不同）；
- 纸张尺寸与页面设置里选的一致，否则内容会被缩放或裁掉。

## 5. CSV 导出

- CSV 带 UTF-8 BOM，Excel 直接打开不乱码。
- 列表导出只导**当前页**（页面会标「当前页」），导出内容跟随当前筛选，不跟随勾选。
- CSV 不截断商品清单：打印列表时商品超过 3 个会以「…」省略，CSV 保留完整名称与编码。

## 6. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| 每页底部空一片 | 虚拟边距预留了几行余量；需要更满可手动调大每页行数 |
| 续页没有表头 | 打印设置里「跨页表头」被关掉了 |
| 两页列宽不一致 | 旧版本问题；现在按整份明细算一次列宽并共用 `colgroup`，请刷新页面重新打印 |
| 一页被拆成两页 | 浏览器缩放不是 100%，或打印对话框的纸张与页面设置不一致 |
| 打印出来没有颜色 | 打印对话框未勾选「背景图形」 |
